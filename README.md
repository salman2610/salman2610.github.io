## 👾 About This Repository

This repo powers my **personal cybersecurity portfolio** — a dark-themed, interactive single-page site built from scratch with vanilla HTML, CSS, and JavaScript. No frameworks. No bloat. Just raw craft.

The site features a **live Three.js WebGL particle background**, a **macOS-style dock navigation**, an **interactive terminal emulator**, a **vulnerability scanner demo**, and **liquid glassmorphism UI** throughout.

## ✨ Site Features

- 🌌 **3D WebGL Background** — Live particle network via Three.js
- 🖥️ **Terminal Emulator** — Typing-animated terminal in the hero section
- 🍎 **macOS Dock Nav** — Magnifying, floating bottom navigation bar
- 🔬 **Vulnerability Scanner Demo** — Interactive clickable grid simulation
- 🔮 **Liquid Glass UI** — Layered blur, shimmer, and depth effects
- 🖱️ **Custom Cursor** — Gradient cursor with hover expansion
- 📱 **Fully Responsive** — Mobile-optimized layout
- ⚡ **Zero Dependencies** — No npm, no build step, pure browser tech
