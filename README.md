## 👾 About This Repository

This repo powers my **personal cybersecurity portfolio** — a dark-themed, interactive single-page site built from scratch with vanilla HTML, CSS, and JavaScript. No frameworks. No bloat. Just raw craft.

The site features a **live Three.js WebGL particle background**, a **macOS-style dock navigation**, an **interactive terminal emulator**, a **vulnerability scanner demo**, and **liquid glassmorphism UI** throughout.
